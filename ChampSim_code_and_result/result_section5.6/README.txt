1. This directory has scripts to generate the results in section 5.6.
2. Set num_prl as per the cores in your machine.
3. Set str_num_test=1 and str_num_train=1 for a test run. Set str_num_test=500 and str_num_train=250 for the exact results generation.
4. Run script.sh.
5. Time and storage requirements.
a) Time requirements: 3 days approx if num_prl is set as 11 in script.sh on a 16-core machine. 
b) Storage requirement: for storing the result files and trace files: 15GB.
6. At the end, the script.sh prints errors and bandwidth results for Test suite.
